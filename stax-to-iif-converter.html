📥 Import into QuickBooks Desktop
  1. Back up first — File → Back Up Company → Create Local Backup
  2. Open import — File → Utilities → Import → IIF Files
  3. Select your file — browse to the downloaded .IIF file, click Open
  4. Confirm success — QB will say "Your data has been imported." Check your account register to verify.
⚠️ Keep a log of date ranges imported to avoid duplicates. QB does not automatically detect IIF duplicates.
