Is your website running an outdated PHP?

We load your home page once, like any visitor, and look only at what it shows publicly: headers, cookie names, links and generator tags. Then we compare any PHP version we find with php.net’s supported list.

Red: end-of-life, no security fixes. Yellow: security fixes only. Green: actively supported, or no sign of PHP. Grey: PHP found but its version is hidden, so we don’t guess. No logins, no scanning of other pages. This is one row of the full KeyRing audit.
