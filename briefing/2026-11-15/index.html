Still running Exchange 2016 or 2019 in the back closet? Microsoft now calls it permanently vulnerable. Plan the move this month

November's Exchange fixes went to the Subscription Edition only. Older Exchange servers got nothing and won't again, and this month's worst email-server flaw needs no click at all. Here's what a small office should check.

Most small offices moved their email to Microsoft 365 years ago. Some didn't, and some moved but kept an old Exchange server around for management. If either sounds like your office, this month's update cycle changes things.

What happened. On Nov. 10, Microsoft released its November security update for Exchange Server, and only for the Subscription Edition (SE). In the same post it said Exchange 2016 and 2019 "are no longer tested for vulnerabilities and there are no updates released," and that anyone still using them "should consider them permanently vulnerable and should upgrade your organization immediately," per Microsoft's Exchange Team. Support ended in October 2025. Microsoft then sold extended security updates, and the final ones for 2016 and 2019 shipped on Oct. 13, per The Register.

What November fixed. The SE update covers nine Exchange flaws, including a critical one, CVE-2026-118207, per The Register. Microsoft says an attacker with any low-level login could send a specially crafted request and run code on the server, with no user interaction. It was not exploited or public at release, but Microsoft rates exploitation "more likely," per Microsoft's Security Update Guide.

The one that needs no click. A separate Windows Search flaw, CVE-2026-116928, is rated 9.8 out of 10. Microsoft says an attacker with no login could send an email with a booby-trapped attachment, and because Exchange automatically indexes attachments, nobody has to open anything, per Microsoft. That fix comes in November's Windows Server updates, not the Exchange update.

Already on Microsoft 365? Exchange Online customers are already protected and don't need to do anything, per Microsoft. The exception is a hybrid setup: any Exchange server you kept, even one used only for management, still needs the update.

Action items for this week.
1. Find out if you have an Exchange server. Ask whoever runs your IT. Include leftover servers from a past move to Microsoft 365 and any PC running the Exchange Management Tools.
2. Check the version. Microsoft's Exchange Server Health Checker script reports whether a server is behind on updates. The current SE build is 15.2.2562.57, released Nov. 10, per Microsoft Learn.
3. If it's SE, install both updates. Install November's Exchange update and November's Windows Server update. Order doesn't matter. Reboot, then confirm all Exchange services have started. If some are disabled, the install was interrupted, per Microsoft.
4. If it's 2016 or 2019, start the move now. Upgrade to Exchange SE or move the mailboxes to Exchange Online. Microsoft's build list shows the last 2019 update was Oct. 13. Every flaw found after that stays open.
5. Don't skip the Windows update in the meantime. The no-click Windows Search fix is in November's Windows Server updates, so install them on the Exchange server today.
